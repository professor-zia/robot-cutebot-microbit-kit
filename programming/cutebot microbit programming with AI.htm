Here is the updated Cutebot code designed to handle 90-degree sharp turns and trigger yellow RGB turn-signal headlights whenever the robot steers left or right.

How It Works

  • Sharp-Turn Memory: Standard line-followers stop when both sensors lose the line (L_R_unline). At a 90-degree corner, the robot overshoots the line completely. This code uses a variable (lastDirection) to remember which way the line turned right before disappearing, allowing the Cutebot to pivot in place until it catches the track again.
  • Pivot Steering: When turning, one wheel reverses (-25) while the other drives forward (30), letting the Cutebot spin tightly around sharp corners instead of making a wide arc.
  • Turn-Signal Headlights: The front RGB LEDs light up green when driving straight, and switch to yellow on the left or right side during turns.

let lastDirection = 0 // 0 = straight, 1 = left, 2 = right

basic.showIcon(IconNames.Happy)

 

basic.forever(function () {

    // Both sensors on the black line -> Drive straight, green headlights

    if (cuteBot.tracking(cuteBot.TrackingState.L_R_line)) {

        lastDirection = 0

        cuteBot.colorLight(cuteBot.RGBLights.ALL, 0x00ff00)

        cuteBot.motors(30, 30)

    }

    // Line shifts right -> Pivot right, right yellow turn signal

    else if (cuteBot.tracking(cuteBot.TrackingState.L_unline_R_line)) {

        lastDirection = 2

        cuteBot.colorLight(cuteBot.RGBLights.RGB_L, 0x000000)

        cuteBot.colorLight(cuteBot.RGBLights.RGB_R, 0xffff00)

        cuteBot.motors(30, -25)

    }

    // Line shifts left -> Pivot left, left yellow turn signal

    else if (cuteBot.tracking(cuteBot.TrackingState.L_line_R_unline)) {

        lastDirection = 1

        cuteBot.colorLight(cuteBot.RGBLights.RGB_R, 0x000000)

        cuteBot.colorLight(cuteBot.RGBLights.RGB_L, 0xffff00)

        cuteBot.motors(-25, 30)

    }

    // Both sensors lose the line (90-degree corner) -> Keep pivoting in last known direction

    else {

        if (lastDirection == 1) {

            cuteBot.colorLight(cuteBot.RGBLights.RGB_L, 0xffff00)

            cuteBot.motors(-25, 30)

        } else if (lastDirection == 2) {

            cuteBot.colorLight(cuteBot.RGBLights.RGB_R, 0xffff00)

            cuteBot.motors(30, -25)

        } else {

            cuteBot.closeheadlights()

            cuteBot.stopcar()

        }

    }

})

Troubleshooting Tip for 90-Degree Corners

  • Verify Left/Right LED Orientation: Depending on your Cutebot hardware revision (V1 vs. V3), RGB_L and RGB_R occasionally appear swapped from the driver's perspective. If the opposite headlight lights up during a turn, simply swap RGB_L and RGB_R in the code.
  • Keep Forward Speed Moderate: Keeping the straight speed at 30 ensures the sensors have enough time to register the corner before the robot shoots past the tape.
